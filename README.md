# 🤖 AI Interview Coach

AI Interview Coach is a simple web app that helps you **practice technical interviews**.
It uses an AI model (via [Groq](https://groq.com)) to:

1. **Generate** a coding or SQL interview question based on the topic and difficulty you pick.
2. **Evaluate** your answer and give you feedback — what's correct, what's missing, tips to improve, and a score out of 10.

Think of it as a free, on-demand mock interviewer.

---

## ✨ Features

- 📝 Generate practice questions for **DSA** (Data Structures & Algorithms) or **SQL**
- 🎚️ Choose difficulty: **Easy**, **Medium**, or **Hard**
- ✅ Submit your answer and get instant AI feedback
- 📊 Get a score (0–10) with explanations, not just a pass/fail
- ⚡ Fast responses powered by Groq's LLM API

## 🚀 Getting Started

Follow these steps to run the project on your own computer.

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/Ai_interview_coach.git
cd Ai_interview_coach
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv

# Activate it
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate
```

### 3. Install the dependencies

```bash
pip install -r backend/requirements.txt
```

### 4. Add your Groq API key

Create a file named `.env` in the project's root folder and add:

```
GROQ_API_KEY="your_groq_api_key_here"
```

You can get a free API key from [console.groq.com](https://console.groq.com/).

> ⚠️ **Never share your real API key or commit your `.env` file to GitHub.** Add `.env` to your `.gitignore` file so it stays private.

### 5. Run the backend server

```bash
uvicorn backend.main:app --reload
```

The API will now be running at:
```
http://127.0.0.1:8000
```

You can view the interactive API docs (auto-generated by FastAPI) at:
```
http://127.0.0.1:8000/docs
```

## 📡 API Endpoints

### `GET /`
Simple health check.

**Response:**
```json
{ "message": "AI Interview Coach API" }
```

### `POST /generate`
Generates a new interview question.

**Request body:**
```json
{
  "topic": "DSA",
  "difficulty": "Medium"
}
```
- `topic` must be `"DSA"` or `"SQL"`
- `difficulty` must be `"Easy"`, `"Medium"`, or `"Hard"`

**Response:**
```json
{ "question": "..." }
```

### `POST /evaluate`
Evaluates your answer to a question.

**Request body:**
```json
{
  "question": "What is a binary search tree?",
  "answer": "A tree where left child < parent < right child..."
}
```

**Response:**
```json
{ "feedback": "..." }
```
